01. Вывод в консоль (print)

Функция print() выводит текст или значения переменных в консоль.

Ваша задача

Напишите код, который выводит на экран строку Hello, Python!

print()

Проверка задания

Программа должна вывести ровно: Hello, Python!

02. Переменные и типы данных

Переменные хранят данные. Основные типы: int (целые), float (дробные), str (строки), bool (истина/ложь).

Ваша задача

Создайте переменную age со значением 25 и переменную name со значением Ivan. Выведите их в консоль через запятую.

Проверка задания

В коде должны быть созданы переменные name и age, а затем выведены.

03. Ввод данных (input)

input() останавливает программу и ждет, пока пользователь введет текст.

Ваша задача

Спросите пользователя "Как тебя зовут? ", сохраните ответ в переменную и поздоровайтесь с ним.

Проверка задания

Код должен запрашивать ввод и выводить "Привет, [имя]!".

04. Условные операторы (if/else)

if позволяет выполнять код только при выполнении условия.

Ваша задача

Напишите программу: если число больше 10, выведите "Много", иначе выведите "Мало". Проверьте на числе 15.

num = 15

Проверка задания

Программа должна вывести "Много".

05. Циклы (for, while)

for используется для перебора последовательностей. range(5) создает числа от 0 до 4.

Ваша задача

Выведите в консоль числа от 1 до 5.

Проверка задания

В консоли должны быть числа 1, 2, 3, 4, 5 с новой строки.

06. Списки (Lists)

Список — это упорядоченная изменяемая коллекция. Индексация начинается с 0.

Ваша задача

Создайте список fruits = ['яблоко', 'банан', 'груша'] и выведите на экран второй элемент.

Проверка задания

В консоли должно быть слово "банан".

07. Словари (Dictionaries)

Словарь хранит пары Ключ: Значение. Доступ к значению через ключ.

Ваша задача

Создайте словарь пользователя с ключами login и status. Выведите статус пользователя.

Проверка задания

В консоли должно быть слово "active".

08. Создание функций

Функции позволяют переиспользовать код. Определяются через def.

Ваша задача

Создайте функцию cube(n), которая возвращает число в третьей степени. Вызовите её для числа 3 и выведите результат.

Проверка задания

В консоли должно быть число 27.
